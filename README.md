# rLive

**rLive** 是基于 **Tauri 2 + React + TypeScript + Rust** 的桌面直播客户端，提供多站点浏览、播放、弹幕与本机数据管理。

## 环境要求

- [Rust](https://www.rust-lang.org/)
- [bun](https://bun.sh/)
- [Tauri 2 平台依赖](https://v2.tauri.app/start/prerequisites/)
- ASR 使用 CrispASR CPU 后端；桌面构建只需要平台对应的 Rust/C++ 编译工具链，Android 还需要 Android SDK、NDK 和 JDK

| Rust           | `D:\dev\rust\{cargo,rustup}` |
| VS Build Tools | `D:\VS\BuildTools`           |
| 临时目录       | `D:\Temp\build`              |

## 开发

```bash
bun install
bun run tauri dev
```

仅启动前端：

```bash
bun run dev
```

构建与测试：

```bash
bun run build
bun run test:unit
cd src-tauri && cargo test --lib
bun run tauri build
```

ASR 固定使用 CPU 后端。CrispASR 会在编译期按目标平台启用可用的 CPU 指令集，并由 Rust 自动读取逻辑处理器数作为线程数；不再提供 GPU Cargo feature 或 GPU 运行时切换。完整参数与 Android 命令见[本地语音字幕](docs/zh/本地语音字幕.md)。

### Windows 交付（WSL → `D:\dev\rLive`）

日常在 WSL 开发，在 Windows 上生成可执行文件：

```bash
# 在 WSL 仓库根目录执行：同步 + 构建
./scripts/build-windows-from-wsl.sh
```

成功产物：

```text
D:\dev\rLive\src-tauri\target\release\rlive.exe
```

规则见 [AGENTS.md](AGENTS.md) 与 `.grok/rules/windows-delivery.md`。

### 正式发布

推送与三处版本一致的 `vX.Y.Z` 标签会触发签名发布流程：生成 Android arm64-v8a APK / AAB 与 `SHA256SUMS.txt`，并创建待人工审核的 GitHub draft Release。签名材料只从受保护的 GitHub `release` Environment 注入；未配置密钥时工作流会失败，不会发布未签名的正式产物。正式发布不提供 Windows 安装包，Windows 可执行文件按上面的「Windows 交付」在本机构建。配置步骤见[发布流程](docs/zh/发布流程.md)。

## 快速使用

1. 首次启动默认打开哔哩哔哩；可在顶部切换站点（哔哩哔哩 / 斗鱼 / 虎牙 / 抖音 / Twitch）。
2. 从首页推荐、分类或搜索进入直播间；房间顶栏左侧的返回图标会回到来源页面，直接打开房间链接时则回到首页。
3. **哔哩哔哩弹幕**：设置 → 账号 → 选择「扫码登录」或「手动输入」保存 Cookie → 进入房间后右侧列表与飘屏生效。普通聊天会按原顺序显示平台图片表情，只加载校验过的 B 站 CDN 图片；意外断线会轮换网关、刷新短时 token 后自动重连。若需发送，先在「设置 → 账号」开启默认关闭的「启用发送功能」，并保存含 `SESSDATA` / `bili_jct` 的 Cookie；发送框位于播放器功能栏中间。**斗鱼**可扫码或手动保存完整本机 Cookie；当前网页对齐的发送链路已在个人直播间验证。每次发送仍以 `chatres(res=0)` 作为平台接收信号，并以正常收弹幕连接的真实回显决定 UI 展示，详见[斗鱼平台 API 文档](docs/zh/斗鱼平台API文档.md)。**虎牙**可扫码登录，或手动保存含数字账号 ID（`yyuid` 或 `udb_uid`）及登录凭据（`udb_n` / `udb_cred` / `udb_biztoken`）的本机 Cookie。
4. **弹幕设置与操作**：右侧标签依次为「弹幕 / 关注 / 设置」；在「设置」中调整显示区域、行数、不透明度、字号、字重、速度、相同内容合并、默认开启的礼物信息过滤和屏蔽词。礼物信息过滤也会隐藏抖音「点赞 × 数量」等平台互动通知。支持 SC 的 B 站房间还可关闭默认开启的画面 SC 卡片。B 站、斗鱼、虎牙可在此会话级开启「自动发送弹幕」：默认关闭且不保存，只有本机发送授权、对应 Cookie/可发送状态及文本校验均有效时可开启。开启时立即发送首段；文本会将换行和连续空白压缩为一个空格，按最多 20 个用户可见字符且不超过平台 UTF-16 上限拆段并循环发送。后续发送起始至少相隔发送间隔；该会话参数默认 20 秒，可在 10–3600 秒间调整，修改会重排下一次发送。编辑文本、切换房间（会清空该会话文本）、离开页面或任何发送失败都会立即停用并显示原因，失败不会自动重试。滑块与屏蔽词输入都会即时生效，屏蔽词会自动保存。点击一条普通弹幕可选择图标「复制」或「+1」；复制会写入剪贴板，「+1」会提交完全相同的一条文本，不会附加“+1”。本机提交不等于送达，右侧列表与飘屏仅在收到平台真实回显后显示。
5. **主播信息 / SC / 关注**：右栏顶部显示主播头像、用户名、所属平台和当前热度；哔哩哔哩醒目留言以卡片叠放在播放器左下角，发送者头像与名称位于身份区，金额保持醒目，安全校验的金额档位颜色用于正文带；头像缺失或加载失败时显示名称首字母。「关注」可直接切换到任一已关注房间，无需先退出当前房间。关注页顶部可按「全部平台」或单个平台筛选；关注状态按钮仅有「全部 / 直播中 / 未开播」，右下角浮动按钮刷新开播状态。
6. **播放器控制**：控制条以透明方式叠放在视频底部，播放期间闲置后自动隐藏，移动、点击或键盘操作可再次显示；打开音量、清晰度或线路选项时会保持显示。焦点位于画面时，`Space` / `K` 播放或暂停，`M` 静音，`F` 全屏。刷新位于暂停左侧；音量按钮展开竖向滑杆；清晰度和线路仅显示当前选择项；右栏、飘屏与全屏均为图标开关。
7. **本地语音字幕**：在「设置 → 播放 → 语音字幕」开启 CPU ASR，可按需开启默认关闭的 VAD，设置 `1–6 秒`字幕窗口（默认 `1 秒`，步长 `0.1 秒`）和 `12–48 px` 字幕字号（默认 `20 px`），再等待 Qwen3-ASR 模型就绪；进入直播间后点击控制栏字幕图标。每个窗口完成后立即更新字幕，不是逐 token 输出。VAD 使用约 865 KiB 的 Silero 模型跳过无语音片段。音频和字幕只在本机处理，关闭总开关会释放模型内存但保留模型文件。
8. **外观**：侧栏「设置」上方只有一个太阳 / 月亮按钮；每次点击会在亮色与暗色模式之间轮换。
9. **抖音 / Twitch**：抖音可匿名浏览首屏分类 / 推荐并播放；搜索需要在「设置 → 账号」选择扫码登录或保存完整网页 Cookie。推荐和分类当前只提供首屏，不会用 Cookie 或 SSR 偏移伪造「加载更多」；抖音网页访问验证仍可能限制扫码或搜索。房间优先从 SSR 取得内部房间号，再使用公开 reflow 数据解析播放信息。抖音弹幕在本机完成 MSSDK 签名后直连官方 WSS，无需外部签名服务。Twitch 支持直播列表、分类、搜索、房间、HLS 播放与匿名 IRC 弹幕；受公开接口限制，浏览结果仅可靠支持首屏，不提供翻页。
10. **IPTV**：从侧栏进入「IPTV」后首先到达频道发现首页，不会自动打开或播放任何流。可加载 IPTV-org 官方日更的中文、中国大陆、东亚或综合公开频道分表；自定义源在「设置 → 网络」保存 HTTP(S) M3U 地址后显示为「自定义源」。页面在手机上使用紧凑来源菜单与双列频道，在桌面上使用分段来源切换与多列频道；两端均提供「更新源」、多关键词搜索、分类筛选、可用状态筛选和「检测可用性」。更新与检测遵循应用代理；检测对当前搜索/分类结果按 URL 去重，单次最多处理前 120 个频道，并显示进度、响应耗时与失败状态。检测结果只保留在当前页面会话，更新或切换来源后清除；“可用”仅表示本次请求取得媒体数据（HLS 同时通过清单头校验），不保证后续分片、解码、地区授权或持续稳定。点击频道才会进入独立的沉浸式播放页（`/iptv/play`）并走 HLS、MPEG-TS 或 FLV 播放路径；返回会回到保留当前来源、分类和搜索条件的频道列表。自定义地址只保存在当前设备，不写入路由或历史，也不会随配置导入导出。

## 架构一览

| 层     | 技术                                                                                                                |
| ------ | ------------------------------------------------------------------------------------------------------------------- |
| 界面   | React + Tailwind v4 + shadcn/ui，中文主界面                                                                         |
| 业务壳 | 首页 / 关注 / 分类 / 历史 / IPTV 频道首页 / IPTV 播放页 / 设置 / 房间页                                             |
| 播放   | `xgplayer` + FLV / HLS / MPEG-TS 协议插件；Rust `stream_proxy` 同源代理拉流                              |
| 站点   | Rust`LiveSite`：bilibili / huya / douyu / douyin / twitch（Twitch 仅可靠支持首屏浏览） |
| 弹幕   | Rust WebSocket → Tauri 事件 → 批处理列表 + 按需 Canvas + 播放器 SC 卡片 + 设置 / 关注侧栏                         |
| 字幕   | Web Audio → 16 kHz PCM → Rust CrispASR 常驻 Qwen3 session → 播放器字幕叠加层                                   |
| 存储   | SQLite：关注、历史、设置、本机 Cookie                                                                               |

详见[架构说明](docs/zh/架构说明.md)。

## 技术边界

B 站、抖音、斗鱼、虎牙均支持扫码或手动 Cookie。B 站、斗鱼和虎牙的单条发送与会话级自动发送共用 `danmaku_send_enabled`、Cookie、文本和冷却校验。斗鱼将本地提交、`chatres(res=0)` 与房间真实回显作为独立状态处理。

不支持支付、送礼、批量发送、自动回复、未知结果自动重试或录制。
