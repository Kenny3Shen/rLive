# Documentation language

When updating user-facing docs for rLive:

1. **Chinese first** — `docs/zh/` and the top of `README.md` are the primary product language.
2. **English second** — keep `docs/en/` in sync for the same topics (user guide, architecture).
3. Update `docs/README.md` index when adding pages.
4. Do not leave README stuck on obsolete facts (e.g. mpv-only, all sites as stubs) after major product changes.
5. Docs-only turns: skip Windows EXE delivery; say so in the reply.
