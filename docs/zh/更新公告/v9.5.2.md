# rLive v9.5.2 更新公告

准备日期：2026-11-18

> [!WARNING]
> v9.5.2 tag 的 Release 工作流未完成，因此本版未发布，也没有可升级的完整跨平台发布资产。Android APK 的 R8、签名验证和最终原生符号检查均已通过；失败发生在 CI 对 `apksigner --print-certs` 输出中的证书 SHA-256 指纹进行解析时。Build Tools 37 的 `V2 Signer:` 前缀增加了分隔冒号，旧的 `awk -F ': '` 固定取第二列，误把标签而不是 digest 当成证书指纹。完整功能说明与兼容新旧格式的解析修复见 [v9.5.3](v9.5.3.md)。

## 构建结果

- v9.5.2 已修复 v9.5.0 的 `sha2` 依赖范围，并通过 `aarch64-linux-android` 的 `cargo check --locked`。
- v9.5.2 已修复 AGP `9.3.1` 优化资源收缩所需的 `android.nonFinalResIds=true`；完整 Universal Release APK 通过 R8、`apksigner --verbose` 的 v2 签名校验、仅 arm64 原生库断言和 native symbols 检查。
- CI run `44242904780` 通过 `bun run check`、生产构建和前端单元测试；前端 1000 项测试通过、0 项失败，Rust 库测试 904 项通过、0 项失败、1 项忽略。
- Release run `44242904886` 在签名后的证书指纹解析阶段失败，未完成 Android artifact 上传与最终跨平台发布。

## 安装与验收

- 请勿使用 v9.5.2 tag 的零散构建产物或其他平台 artifact 升级。
- 其他平台的零散构建结果不能组成完整发布；最终版本与 Windows 安装包验收必须使用 v9.5.3 新 run 的产物。

v9.5.0 与 v9.5.1 的失败记录见 [v9.5.0 公告](v9.5.0.md)和 [v9.5.1 公告](v9.5.1.md)。
