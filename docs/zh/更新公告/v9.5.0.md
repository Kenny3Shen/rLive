# rLive v9.5.0 更新公告

准备日期：2026-11-18

> [!WARNING]
> v9.5.0 tag 的 Release 工作流未完成，Android 构建失败，因此本版未发布，也没有可升级的完整发布资产。B 站授权缓存所在公共代码使用 `sha2`，但依赖被限定为非 Android 目标，Android 编译时无法解析该 crate。v9.5.1 修复该依赖后又在 Android R8 阶段失败，v9.5.2 随后在 CI 证书指纹解析阶段失败；最终修复与完整功能说明见 [v9.5.3](v9.5.3.md)。

## 失败原因

- `src-tauri/Cargo.toml` 原先只在非 Android 目标中声明 `sha2`。
- B 站授权缓存共用代码在 Android 构建中也会引用 `Sha256`，导致 Android Release 编译失败。
- v9.5.1 将该依赖放入通用依赖并通过 Android 定向检查，但完整 APK 构建随后被 AGP 资源收缩配置拦截；v9.5.2 修复 APK 构建后又暴露 CI 证书输出解析误报，最终由 v9.5.3 一并修复。

## 安装与验收

- 请勿使用 v9.5.0 tag 的零散构建产物或其他平台 artifact 升级。
- 本地 `bun run check`、1000 项前端单元测试、生产构建和 904 项 Rust 库测试通过，但这些桌面基线检查没有发现 Android 目标的依赖范围错误。
- v9.5.0 没有可发布的跨平台安装包；最终验收记录见 [v9.5.3](v9.5.3.md)。
