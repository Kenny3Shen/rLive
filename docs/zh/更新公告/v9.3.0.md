# rLive v9.3.0 更新公告

发布日期：2026-11-04

本次更新集中完善 B 站视频下载与离线回放，并把录制库、下载任务和本地媒体播放统一到关注页；同时修复若干播放与页面动效问题，并调整 Rust 开发构建配置。

## B 站视频下载与离线回放

- 视频卡片支持桌面右键、Android 长按直接下载，播放页也可选择画质。下载沿用当前 B 站账号的可用权限，同一时间运行一个任务。
- 下载队列支持暂停、继续、重试和删除，并通过 Range 断点续传；切换页面、最小化窗口或重启应用后，未完成任务会保留并可继续。
- 桌面端使用 FFmpeg、Android 使用 MediaMuxer 把分离的视频与音频轨合并为单个 MP4，不需要用户另行处理 m4s 文件。
- 下载时缓存当前账号可获取的字幕和当前分 P 弹幕。应用内离线播放支持进度拖动、倍速、全屏、断点续播、字幕语言切换与弹幕开关。
- 已完成文件可从下载列表整卡进入应用内播放器，也可交给系统播放器；桌面端还支持定位下载目录。
- Android 下载保存在应用私有目录，通过 `FileProvider` 授权系统播放器读取。应用内播放只支持已经完成的 MP4，不支持边下边播；离线回放不加载评论。

使用说明见[视频下载](../视频下载.md)，功能边界见[用户指南](../用户指南.md)。

## 关注页与本地媒体

- 录制库和下载任务统一进入关注页的「录制」「下载」页签，沿用相同的左右筛选布局和窄屏横向筛选；旧深链接继续兼容。
- 关注导航、录制页签和下载页签会显示进行中的任务数量，数量为 0 时隐藏，超过 99 显示 `99+`。
- 录制与下载列表改用统一的本地媒体卡片，集中展示封面、状态、进度与文件操作；完成项可直接点击播放。
- 录制回放补齐共享控制栏、弹幕页签、弹幕定位与进度跟随，并修正画布缩放和侧栏布局。
- 本地下载播放器补齐返回、文件操作、倍速、全屏、Android 系统音量和观看进度保存。

## 修复

- 修复桌面刷新按钮在页面离场后仍常驻的问题。
- 修复下载、录制等页面自动取数时下拉刷新指示器强制展开造成的页面抖动。
- 修复播放页返回时旧页面短暂重播入场动画导致的闪烁。

## 安装与升级

- 版本号为 `9.3.0`。Windows、macOS、Linux 和 Android 安装包以本次 Release 资产为准。
- 常规升级可直接覆盖安装，配置、观看历史、录制与下载目录通常保留；升级前仍建议备份数据库和重要媒体文件。
- Windows 安装包未做 Authenticode 签名，SmartScreen 可能提示未知发布者。macOS 未做 Apple 签名与公证，首次打开需在「系统设置 → 隐私与安全性」允许，或执行 `xattr -cr /Applications/rLive.app`。
- Android 必须使用与已安装版本相同的签名升级。若签名不一致，应用无法覆盖安装；此时需先备份，再卸载旧版后安装。卸载会清除应用私有数据，包括应用内下载。

## 开发者说明

- 本地、CI 与发布构建固定到 Rust `nightly-2026-11-04`；dev/test 使用 `opt-level = 1`、`debug = 0`、`incremental = false`。
- Windows 干净构建对比中，开发 `target` 实际分配从 6,427,462,920 B 降至 1,574,620,520 B（-75.5017%），`rlive.exe + rlive.pdb` 从 300,709,376 B 降至 38,074,368 B（-87.3385%）。
- 同口径 Windows 构建耗时从 307 秒增至 433 秒（+41.0423%）。Linux/WSL 单次干净构建的开发产物减少 76.4071%，耗时增加 52.844%。
- Windows 的开发构建体积使用了非破坏的测试前重建口径：从测试后总量排除唯一的测试 crate 目录，不能视为同一时刻直接采样的原快照；耗时均只有一次样本。
- 上述收益只针对开发/测试 `target` 与调试产物，不代表安装包会同比缩小，也不代表播放帧率或运行性能提升。release profile 继续使用 `opt-level = 3`、LTO、`panic = "abort"` 和 `strip`。
- 本次未构建或验证 release、Tauri 安装包、macOS、Android 产物及 GUI 运行性能。WSL 库测试为 838 通过、1 忽略；Windows 首轮测试有 1 项实网瞬态失败，同一产物重跑为 833 通过、1 忽略。

复现步骤与完整口径见[开发指南](../开发指南.md)，原始数据见 [`rust-target-2026-11-04.json`](../../bench/rust-target-2026-11-04.json) 和 [`rust-target-windows-2026-11-04.json`](../../bench/rust-target-windows-2026-11-04.json)。
