# rLive v9.7.0 更新公告

本版接入 YouTube 直播与实时聊天，新增关注主播的开播通知，并完善 AcFun 点播和 B 站竖屏播放体验。

## 主要变化

- **YouTube 直播**：可以搜索公开直播，也可通过直播链接或频道进入；支持关注频道、切换 HLS 清晰度和查看实时聊天。桌面端可在多画面中观看。
- **开播通知**：可在设置中开启，默认关闭。应用运行期间，当已关注的主播从未开播变为开播时发送提醒，同一场次不重复通知。修复 Android 用户在系统设置中恢复通知授权后，应用内权限状态没有刷新的问题。
- **AcFun 点播**：支持观看、复制和收藏弹幕，新增观看历史、分 P 进度续播和自动连播；播放控制栏与设置沿用 B 站点播交互。
- **B 站竖屏播放**：移动端符合条件的单 P 视频直接进入短视频界面，避免经过中间播放页。切换视频时作者、进度和控制栏随画面同步滑动；详情抽屉按内容调整高度，可长按画面及黑边倍速播放，或左滑打开 UP 主投稿列表。桌面端恢复竖屏视频首帧前的详情占位。
- **评论显示**：修复部分用户名的末字被评论区按钮圆角裁切的问题。

## 已知限制

- YouTube 目前仅支持公开直播和只读聊天，不支持登录、发言或普通视频点播；上游访问限制仍可能影响搜索、播放和聊天。
- 开播通知需要应用正在运行，并受系统通知权限约束；不会补发应用启动前已开播的场次。
- Android 真机长按与最终安装包验收尚未完成；模拟器及桌面合成触摸结果不能替代真机验证。
- Windows 安装包未做 Authenticode 签名；macOS 安装包未做 Apple 签名与公证，首次打开可能需要手动允许。
