# rLive v9.4.0 更新公告

准备日期：2026-11-11

本版新增抖音弹幕发送，改进抖音搜索与移动端导航，并集中修复播放页返回、视频首片加载和卡片响应问题。

## 主要变化

- **抖音弹幕发送**：登录抖音账号后，可在直播间发送普通文本弹幕，并支持手动发送、`+1` 和会话级自动发送。发送成功后，平台返回的弹幕会接入现有弹幕时间轴，按消息 ID 去重并显示服务器确认回显。
- **抖音精确搜索**：在抖音搜索的「全部」页输入公开房间号或官网房间链接时，会并行执行精确房间查询和关键词搜索，合并并去重结果；某一路查询失败时，仍可保留另一条链路的有效结果。
- **直播首页与移动端导航**：原「首页」入口更名为「直播」，使用更明确的图标。移动端的直播平台、关注、视频、IPTV 和历史页签改为只显示图标，保留无障碍名称、选中状态与任务提示。
- **播放与返回体验**：优化播放页退出动画、返回按钮位置和 IPTV 标题样式；修复视频返回穿透、快速连点重复回退，以及首片尚未加载时的恢复计时问题。
- **视频加载稳定性**：检测不完整的 VOD 首片响应，在共享内存和整轮时间预算内重新获取完整分片；自动恢复迟到的结果不会覆盖已经恢复的媒体会话。
- **列表响应**：直播卡片按需挂载菜单和关注状态，关注操作复用已有缓存；首页切换优先提交当前平台，减少大列表挂载造成的选中态延迟。录制与下载卡片统一封面、信息层级和操作菜单。

## 使用说明

抖音弹幕发送需要有效的抖音账号登录。平台或房间限制发送时，界面会显示失败状态；发送成功后可观察服务器确认回显。视频加载恢复依赖网络可用，代理或上游持续失败时仍会停止重试并显示错误。

## 构建与验收

- 版本元数据统一为 `9.4.0`，安装包以本次 GitHub Release 资产为准。
- 本地前端格式、类型和 lint 检查通过，945 项前端单元测试与生产构建通过；Rust 库测试 867 项通过、1 项忽略。
- Windows 发布包将使用隔离目录执行安装包解包启动、联网播放和核心导航验收。当前没有连接 Android arm64 真机，也没有 macOS 实机，这两平台以发布工作流构建和自动检查结果为准，不宣称完成人工安装验收。
- Windows 安装包未做 Authenticode 签名；macOS 安装包未做 Apple 签名与公证，首次打开可能需要在系统设置中允许。
