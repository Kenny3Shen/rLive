# rLive v9.5.3 更新公告

准备日期：2026-11-18

本版承接未发布的 v9.5.0、v9.5.1 与 v9.5.2，新增 AcFun 直播、视频与文章浏览和 xASR 中英字幕模型，改进字幕、B 站内容体验与页面加载性能，并修复 Android Release 构建中的依赖范围、资源收缩和签名证书输出解析问题。

## 主要变化

- **AcFun 内容接入**：新增 AcFun 直播列表、分类、搜索和 FLV 播放；视频支持热门、频道、搜索、多 P 与画质切换；文章支持分类、搜索和应用内安全图文阅读。文章正文会转换为受控的结构化内容，不直接执行平台 HTML。
- **字幕体验升级**：本地语音字幕新增体积更小的 xASR 中英模型。字幕框顶栏统一整合原文、译文、字号、显示模式和独立窗口操作，并适配直播、IPTV、多画面与 B 站视频。
- **B 站浏览增强**：点击评论区的有效用户名可查看该用户投稿，覆盖主评论、回复预览、完整回复和短视频评论；移动端打开竖屏单 P 稿件时会在确认画幅后直接进入短视频流。
- **播放与导航修复**：桌面播放页保留左侧导航，并在全屏时按状态收起；B 站推荐首页以 20 分钟为有效期自动更新；从播放页返回列表时复用已有封面缓存，减少重复加载。
- **加载性能改进**：首页手动刷新只重建第一页；B 站授权校验和 WBI 密钥请求增加短期缓存与并发合并；VOD 复用同一轮在途取流，慢分片连续无进展时切换完整备用 Range。
- **界面一致性**：设置页与直播、视频、录制回放侧栏共享完整播放设置；多画面添加直播间弹窗改用紧凑的平台、房间号和候选卡片布局。
- **Android 构建修复**：将 B 站授权缓存公共代码所需的 `sha2` 移入通用依赖；设置 `android.nonFinalResIds=true` 以满足 AGP `9.3.1` 优化资源收缩；证书指纹解析改用最后一个字段，兼容 Build Tools 37 的 `V2 Signer:` 输出。

## 使用说明

AcFun 直播沿用现有平台切换、关注和观看历史入口；视频与文章在「视频」页选择 AcFun 后浏览。xASR 适合中英双语和低资源环境，首次选择时按需下载模型；Qwen3-ASR 继续提供更广的语言覆盖和热词支持。

## 已知限制

- AcFun 为第一期接入，暂不支持账号登录、实时弹幕或弹幕发送、视频或文章评论互动、B 站式视频下载、点播续播记录、作者关注和文章互动。公开内容之外的门票、付费、登录或地区限制不会被绕过。
- xASR 当前会在 Windows 上安全回退 CPU。CrispASR `v0.8.48` 的 CUDA 后端缺少 xASR 所需卷积核，选择「自动」或「CUDA」不会改变实际 provider；xASR 也不使用热词，目前尚未完成同口径性能 benchmark。
- 字幕翻译只发送已定稿文本到 Google 翻译，需要用户主动开启，并依赖网络、地区策略和上游接口；可能出现限流或暂时不可用。
- 独立字幕窗口只在直播间提供入口。Android 不支持多画面、录制和本地语音字幕。
- 桌面本地语音字幕仍需首次联网下载运行库和所选模型。Windows 安装包未做 Authenticode 签名，可能触发 SmartScreen；macOS 安装包未做 Apple 签名与公证。

## 构建与验收

- v9.5.2 基线 CI run `44242904780` 的前端与 Rust 作业通过；前端共运行 1000 项测试、117 个文件，1000 项通过、0 项失败。Rust 库测试 904 项通过、0 项失败、1 项忽略，忽略项为 `asr::tests::crispasr_end_to_end`，需要真实运行库模型。上述数字属于旧基线，不冒充 v9.5.3 已重新运行全套测试。
- v9.5.2 的完整 Universal Release APK 已通过 R8；`apksigner --verbose` 确认 v2 签名有效，最终 APK 仅包含 `lib/arm64-v8a/librlive_lib.so`，原生符号检查通过。该本地验证使用 v9.5.2 根版本，本地 NDK `29.0.13846066` 与 CI 的 `29.0.14206865` 存在补丁版本差异，且尚未进行 Android 真机验收。
- v9.5.2 Release 的失败原因是 CI 证书指纹解析误报，不是 APK 签名失败。v9.5.3 仍需由新一轮 Release 工作流完成 Android artifact 上传与签名验证，并重新构建 Windows、macOS、Android 与 Linux 全部产物。
- v9.5.2 旧 Release run 的 Windows x64 job 已成功，NSIS 与 MSI 实际载荷断言通过；macOS arm64 构建也已成功。这些旧 run 结果用于确认既有平台检查有效，不替代 v9.5.3 新 CI 的最终全平台结果。
- v9.5.2 的 Windows artifact 即使可用，也只用于验收路径诊断，不能作为最终版本依据。最终 Windows 安装、启动和核心功能验收必须针对 v9.5.3 产物。
- AcFun 首期已在 Windows WebView2 开发主窗口完成浏览、播放和文章阅读验证；Android、macOS 与 Linux 的 AcFun 浏览、播放和阅读仍需在发布验收中确认。

v9.5.0、v9.5.1 与 v9.5.2 的失败记录见 [v9.5.0 公告](v9.5.0.md)、[v9.5.1 公告](v9.5.1.md)和 [v9.5.2 公告](v9.5.2.md)。v9.5.3 的最终 CI 与跨平台验收结果仍待新 run 完成后补充。
