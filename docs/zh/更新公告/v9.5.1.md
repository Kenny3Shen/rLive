# rLive v9.5.1 更新公告

准备日期：2026-11-18

> [!WARNING]
> v9.5.1 tag 的 Release 工作流未完成，Android 构建失败，因此本版未发布，也没有可升级的完整发布资产。AGP `9.3.1` 的优化资源收缩要求 `android.nonFinalResIds=true`，但工程仍为 `false`，R8 阶段失败。完整功能说明与三项 Android 发布修复见 [v9.5.3](v9.5.3.md)。

## 构建结果

- v9.5.1 已修复 v9.5.0 的 `sha2` 依赖范围，并通过 `aarch64-linux-android` 的 `cargo check --locked`。
- CI run `44238998351` 通过 `bun run check`、生产构建和前端单元测试；前端 1000 项测试通过、0 项失败，Rust 库测试 904 项通过、0 项失败、1 项忽略。
- Release run `44238998321` 的 Android job 在 R8 优化资源收缩阶段失败，未生成签名 APK，整体 Release 未发布。
- 这些检查没有覆盖完整的 Android APK 构建，也不能作为 v9.5.1 已发布的依据。

## 安装与验收

- 请勿使用 v9.5.1 tag 的零散构建产物或其他平台 artifact 升级。
- 其他平台的零散构建结果不能组成完整的跨平台发布；Windows 构建被取消且未生成 artifact，最终验收以 v9.5.3 新 run 的全部产物为准。

v9.5.0 的失败记录见 [v9.5.0 公告](v9.5.0.md)。
