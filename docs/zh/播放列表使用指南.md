# 播放列表功能使用指南

## 快速开始

### 如何使用播放列表

1. **打开番剧/影视播放页**
   - 播放任意番剧或影视作品的一集

2. **查看分集列表**
   - 点击右侧栏的「分集」标签
   - 可以看到所有可播放的剧集

3. **开始使用播放列表**
   - **播放全部**：从第一集开始连续播放所有剧集
   - **加入列表**：从当前集开始设置播放列表

### 自动切集

- 默认开启：搜索、UP 主投稿和选集/合集队列有下一项时，延迟 1 秒自动跳转下一项
- 关闭方法：点击播放器控制栏的设置按钮 → 播放设置 → 关掉「自动切集」开关

### 自动连播

- 默认开启：当前队列没有下一项时（最后一集播完、推荐/热门/相关流结束），延迟 3 秒从当前视频的相关视频列表第一个接着播
- 关闭方法：播放设置 → 关掉「自动连播」开关；番剧/影视（PGC）没有相关视频列表，不显示这一项
- 与「自动切集」的分工：还有下一集时由它接手，没有下一集才轮到相关视频

### 循环播放

- 默认关闭：开启后播完当前视频从头重播，不会跳到下一集（循环优先于两种连播）
- 开启方法：点击播放器控制栏的设置按钮 → 播放设置 → 打开「循环播放」开关；单个视频也能用

### 键盘快捷键

播放视频时使用以下快捷键：

- **N 或 ]**：跳到队列下一集
- **P 或 [**：跳到队列上一集
- **空格或 K**：播放/暂停
- **← →**：快退/快进 5 秒
- **M**：静音/取消静音
- **F**：全屏/退出全屏

### 播放进度显示

播放器控制栏中间会显示当前播放位置，例如：

```
3 / 12
```

表示当前播放第 3 集，共 12 集。

## 设置选项

通过播放器控制栏的设置菜单可以调整（都是开关行）：

### 自动切集

- **开启**（默认）：搜索、UP 主投稿和选集/合集队列有下一项时，延迟 1 秒自动播放下一项
- **关闭**：没有下一集时交给「自动连播」决定

### 自动连播

- **开启**（默认）：当前队列没有下一项时，延迟 3 秒播放当前视频的相关视频列表第一个；播放后本轮队列换成相关流
- **关闭**：没有下一集时停在当前视频
- 该项只在普通视频（UGC）出现；番剧/影视没有相关视频列表

### 循环播放

- **关闭**（默认）：播完按「自动切集」→「自动连播」的顺序接手
- **开启**：播完当前视频从头重播，优先于两种连播

## 注意事项

1. **来源队列优先**：多 P/合集信息不会覆盖打开视频时的来源列表。没有来源队列的多 P 直链自动建立选集队列；主动点选分 P 或合集分集时，才切换到对应选集队列。
2. **列表不持久化**：刷新页面后需要重新设置播放列表；仅多 P 直链自动重建选集队列，UP 来源标记不保存。
3. **单一列表**：当前只能有一个播放列表。沿队列切换会保留它；从新列表点开视频时替换为新列表，并清除不再适用的 UP 来源标记。
4. **相关视频队列**：自动连播相关视频后，新队列是该视频的相关视频列表，后续连播沿新队列进行。

## 常见问题

**Q: 为什么没有播放控制按钮？**
A: 「播放全部」和「加入列表」在番剧/影视的分集列表中显示。普通视频从列表卡片进入时自动建立来源队列；多 P 直链可自动建立选集队列，合集需要主动点选分集。

**Q: 控制条上的「下一个」按钮什么时候出现？**
A: 只在该视频自身有选集（番剧/影视的分集、稿件的分 P 或合集分集），且当前不在最后一集时出现，点击播放选集里的下一集。它不沿来源队列（推荐、搜索、UP 投稿），那种队列用键盘 `N` / `]`、`P` / `[` 或滑动切换。

**Q: 多 P 视频怎么连播？**
A: 从来源列表进入时先沿来源队列播放；要沿分 P 连播，在右侧栏「选集」页签主动选择一个分 P 即可。没有来源队列的多 P 直链会自动建立全部分 P 的队列，自动连播与快捷键沿该队列走。

**Q: 如何停止自动播放？**
A: 播放设置 → 关掉「自动切集」和「自动连播」；若想反复看同一集，改为打开「循环播放」

**Q: 播完最后一集后会自动播什么？**
A: 打开「自动连播」时，3 秒后自动播放当前视频的相关视频列表第一个（番剧/影视没有相关视频，播完即停）；关掉它就停在当前视频。

**Q: 刷新页面后播放列表还在吗？**  
A: 播放列表状态不会保存，需要重新设置。但您的偏好设置（自动切集、自动连播、循环播放）会保留。
