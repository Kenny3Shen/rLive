# 播放列表功能使用指南

## 快速开始

### 如何使用播放列表

1. **打开番剧/影视播放页**
   - 播放任意番剧或影视作品的一集

2. **查看分集列表**
   - 点击右侧栏的「分集」标签
   - 可以看到所有可播放的剧集

3. **开始使用播放列表**
   - **播放全部**：从第一集开始连续播放所有剧集
   - **加入列表**：从当前集开始设置播放列表
   - **切换顺序**：点击右上角图标在正序/倒序间切换

### 竖屏短视频模式

从推荐、热门/分区、搜索、UP 主投稿或相关视频列表点开视频后，即可沿当前已加载列表切换。移动端识别到竖屏视频会自动沉浸全屏：上滑播放下一个、下滑播放上一个，单击暂停/继续，长按临时 3 倍速，双击不切换全屏。进入后滑到横屏视频也保持竖屏沉浸，可继续上下换片。换片支持跟手预览、快速甩动和回弹，横滑、多指和控件操作不会切片。

第一条与最后一条只提示到达边界，不循环跳转。切换顺序遵循播放列表的正序/倒序偏好；无列表的直链不启用滑动，也不会在播放页自动加载无限推荐。

桌面端在播放器画面内向下滚轮播放下一条、向上播放上一条，横屏项也可继续换片；一次连续惯性滚动只换一条，列表边界不循环。详情区与控件/菜单仍按原有方式滚动，横向滚动和缩放操作不换片。画面不显示上下滑动提示文字。

标题仅展示，不提供「详情」按钮；点「评论」或控制栏的退出全屏按钮进入普通详情页，再点「返回短视频」、全屏按钮或 Android 返回键恢复沉浸，视频进度、暂停状态不变。详情内只滚动内容，不上下换片。短视频模式播完循环当前视频，普通详情模式才遵循下方的循环/连播设置；两套行为不相互改写偏好。

用户信息采用两行布局：左侧头像，右侧依次为用户名、粉丝/视频图标及数量，视频标题位于下方，与普通详情页的统计样式一致。进度条和控制栏常驻；「隐藏用户和视频信息」只隐藏这部分信息，不隐藏评论、进度条或控制栏，再点同一按钮恢复。换片保持信息显隐状态。

短视频沿默认来源队列播放时不显示序号。点击头像打开 UP 主投稿抽屉并选择视频后，改用该 UP 当前已加载的投稿队列，自动关闭抽屉，时间轴旁显示 `x/y`；普通详情页仍保留多项播放列表的序号。

### 自动播放下一集

- 普通详情模式默认开启：每集播放结束后 1 秒自动跳转到下一集；短视频模式固定单条循环
- 关闭方法：点击播放器控制栏的设置按钮 → 播放列表设置 → 取消勾选「自动播放下一集」

### 循环播放

- 默认关闭：开启后播完当前视频从头重播，不会跳到下一集（循环优先于自动播放下一集）
- 开启方法：点击播放器控制栏的设置按钮 → 播放偏好 → 勾选「循环播放」；单个视频也能用

### 键盘快捷键

播放视频时使用以下快捷键：

- **N 或 ]**：跳到下一集
- **P 或 [**：跳到上一集
- **空格或 K**：播放/暂停
- **← →**：快退/快进 5 秒
- **M**：静音/取消静音
- **F**：全屏/退出全屏

### 播放进度显示

播放器控制栏中间会显示当前播放位置，例如：

```
3 / 12
```

表示当前播放第 3 集，共 12 集。

## 设置选项

通过播放器控制栏的设置菜单可以调整：

### 自动播放下一集

- **开启**（默认）：每集结束后自动播放下一集
- **关闭**：每集结束后停止播放

### 循环播放

- **关闭**（默认）：按播放列表设置决定播完后的行为
- **开启**：播完当前视频从头重播，优先于「自动播放下一集」

### 倒序播放

- **关闭**（默认）：按 1、2、3... 正序播放
- **开启**：按 ...3、2、1 倒序播放

## 注意事项

1. **来源队列优先**：多 P/合集信息不会覆盖打开视频时的来源列表。没有来源队列的多 P 直链自动建立选集队列；主动点选分 P 或合集分集时，才切换到对应选集队列。
2. **列表不持久化**：刷新页面后需要重新设置播放列表；仅多 P 直链自动重建选集队列，UP 来源标记不保存。
3. **单一列表**：当前只能有一个播放列表。沿队列切换会保留它；从新列表点开视频时替换为新列表，并清除不再适用的 UP 来源标记。

## 常见问题

**Q: 为什么没有播放控制按钮？**
A: 「播放全部」和「加入列表」在番剧/影视的分集列表中显示。普通视频从列表卡片进入时自动建立来源队列；多 P 直链可自动建立选集队列，合集需要主动点选分集。控制条「下一个」按钮只在队列还有后续项时出现。

**Q: 多 P 视频怎么连播？**
A: 从来源列表进入时先沿来源队列播放；要沿分 P 连播，在右侧栏「选集」页签主动选择一个分 P 即可。没有来源队列的多 P 直链会自动建立全部分 P 的队列，自动连播与快捷键沿该队列走。

**Q: 如何停止自动播放？**
A: 播放器设置菜单 → 播放偏好 → 取消勾选「自动播放下一集」；若想反复看同一集，改勾选「循环播放」

**Q: 倒序播放从哪一集开始？**  
A: 点击「播放全部」会从最后一集开始倒序播放。

**Q: 刷新页面后播放列表还在吗？**  
A: 播放列表状态不会保存，需要重新设置。但您的偏好设置（自动播放、播放顺序、循环播放）会保留。
