# 播放列表功能使用指南

## 快速开始

### 如何使用播放列表

1. **打开番剧/影视播放页**
   - 播放任意番剧或影视作品的一集

2. **查看分集列表**
   - 点击右侧栏的「分集」标签
   - 可以看到所有可播放的剧集

3. **开始使用播放列表**
   - **播放全部**：从第一集开始连续播放所有剧集
   - **加入列表**：从当前集开始设置播放列表
   - **切换顺序**：点击右上角图标在正序/倒序间切换

### 自动播放下一集

- 默认开启：每集播放结束后 1 秒自动跳转到下一集
- 关闭方法：点击播放器控制栏的设置按钮 → 播放列表设置 → 取消勾选「自动播放下一集」

### 键盘快捷键

播放视频时使用以下快捷键：

- **N 或 ]**：跳到下一集
- **P 或 [**：跳到上一集
- **空格或 K**：播放/暂停
- **← →**：快退/快进 5 秒
- **M**：静音/取消静音
- **F**：全屏/退出全屏

### 播放进度显示

播放器控制栏中间会显示当前播放位置，例如：
```
3 / 12
```
表示当前播放第 3 集，共 12 集。

## 设置选项

通过播放器控制栏的设置菜单可以调整：

### 自动播放下一集
- **开启**（默认）：每集结束后自动播放下一集
- **关闭**：每集结束后停止播放

### 倒序播放
- **关闭**（默认）：按 1、2、3... 正序播放
- **开启**：按 ...3、2、1 倒序播放

## 注意事项

1. **多 P 视频自动连播**：多分 P 的普通视频（右侧栏「选集」页签）进入播放页后自动按分 P 顺序接管播放列表，无需手动「加入列表」；合集稿件同理沿合集分集连播
2. **列表不持久化**：刷新页面后需要重新设置播放列表（多 P/合集稿件会自动重建）
3. **单一列表**：当前只能有一个播放列表，切换视频会清空之前的列表

## 常见问题

**Q: 为什么没有播放控制按钮？**
A: 播放控制按钮仅在番剧/影视的分集列表中显示，普通视频暂不支持。

**Q: 多 P 视频怎么连播？**
A: 无需操作。打开多分 P 视频的播放页，右侧栏出现「选集」页签（当前 P 高亮），播放列表自动设为全部分 P，自动连播与快捷键沿分 P 列表走。

**Q: 如何停止自动播放？**
A: 播放器设置菜单 → 播放列表设置 → 取消勾选「自动播放下一集」

**Q: 倒序播放从哪一集开始？**  
A: 点击「播放全部」会从最后一集开始倒序播放。

**Q: 刷新页面后播放列表还在吗？**  
A: 播放列表状态不会保存，需要重新设置。但您的偏好设置（自动播放、播放顺序）会保留。
