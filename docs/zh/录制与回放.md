# 录制与回放

本篇讲桌面端的直播 / IPTV 实时录制、录制库回放和 ASS 弹幕导出。
需要把直播存到本地、或想找回已录内容时看这里。
浏览、弹幕、字幕等日常使用见[用户指南](用户指南.md)。

> 录制只在 Tauri 桌面端启用，Android、iOS 和浏览器预览不会显示录制入口。

## 1. 开始一次录制

1. 进入直播间或 IPTV 的 `/iptv/play` 播放页。
2. 点击顶部标题栏右侧的录制图标（直播间入口位于「定时关闭」旁）。
3. 在弹层中确认内容。直播还可勾选「包含弹幕」和「离开页面后继续录制」。
4. 再次点击方形图标即停止并保存，也可在侧栏「录制」中停止。

默认包含弹幕（默认值可在「设置 → 录制设置」调整）；后台录制默认开启，只能按任务关闭。一个客户端同时录制的路数在「设置 → 录制设置 → 最大同时录制」调整，默认 4 路，范围 1–6 路。录制后端固定为进程内 Rust FFmpeg。

不进直播间也可以录：在关注页右键正在直播的主播 Card 选择「开启录制」，按默认清晰度和已记忆线路直接后台开始。

### 离开页面时

录制中离开直播间或 IPTV 播放页会弹出确认框，可选「留在直播间/频道」「继续录制并离开」「停止录制并离开」。选择继续会转为后台任务，开启「包含弹幕」时弹幕连接一并转交后台。开始前勾选「离开页面后继续录制」则不再询问。

### 自动录制关注主播

在关注页右键主播 Card 勾选「自动录制」，Card 底部会显示状态。应用会立即检查一次，之后每分钟轮询已开启的主播，发现开播后自动解析播放源并创建后台任务；已有任务会跳过，不重复录制。取消勾选只停止后续自动启动，不影响正在进行的录制。该功能仅在桌面应用运行时工作，关闭应用后不驻留后台。

### 自动分割

「设置 → 录制设置 → 自动分割时长」可设单段上限，范围 0–1440 分钟，0 为关闭。达到上限后当前段正常收尾并发布，任务自动续录下一段，每段可独立回放、定位、复制或删除。设置在任务开始时固化，修改不影响正在进行的任务。仅适用于 FLV、HLS 和 MPEG-TS；原生 MP4/WebM 直连保存保持单文件。

## 2. 录制库与回放

侧栏「录制」进入录制库，有任务时入口显示进行中数量徽标。顶栏提供「全部」「录制中」「已录制」三个 Tab（「已录制」含已保存、已中断和失败），最右侧是「保存位置」入口。左侧先按平台筛选、再按主播头像选择用户，右侧是该用户的录播列表。

- 录制中的 Card 实时更新时长、大小和弹幕数量，可直接停止并保存。
- 已保存的 Card 点击进入独立回放页：左侧播放器、右侧主播与录制信息，窄窗口改为上下排列。
- 控制条与直播间一致（进度、播放/暂停、静音、弹幕、全屏），「回放设置」可选 0.5x–2x 速度；支持单击播放/暂停、双击全屏，以及 `Space` / `K`、左右方向键、`M`、`F`。全屏时顶部 HUD 左侧有返回箭头，点击退出全屏。
- 进度条区分已缓冲与已播放范围，拖动时只预览，松手才跳转。2.0 起新建的 FLV 录制带关键帧索引，大幅跳转直接走本地文件 Range。
- 每段录制左侧小卡的文件夹 / 删除图标可定位文件或删除录制。删除需确认，删除后无法从应用恢复。

带弹幕轨的录制在回放中同步绘制弹幕，显示区域、透明度、字号、描边、速度、内容合并、礼物过滤、醒目留言和屏蔽词与直播间共用同一组设置。回放弹幕整段一次排轨，同一行相邻弹幕保留安全间距，放不下的先在 5 秒内推后到最早空出的行，仍放不下才丢弃，因此不会互相遮挡。Bilibili 图片表情按图片绘制，加载失败时回退 `[表情]` 文字。刷屏时段的弹幕密度受播放器高度、显示区域和字号限制，调大显示区域或调小字号可看到更多。

## 3. 弹幕轨与 ASS 导出

「包含弹幕」保存的是录制目录内的 `danmaku.jsonl` 可开关 sidecar，不烧录进视频、不需要转码。IPTV 没有应用内弹幕，该选项不可用。

已保存且带弹幕轨的 Card 上有字幕图标，点击即把 `danmaku.jsonl` 转为 ASS 滚动弹幕字幕，写入同一目录并与媒体同名（如 `主播_标题_时间.ass`）。PotPlayer、mpv、VLC 等会按同名规则自动加载。转换在本地完成，不修改媒体、不转码，可重复导出覆盖。录制中的任务需先停止保存才能导出。

「设置 → 录制设置 → 导出 ASS 弹幕 → 配置选项」可单独设置视频分辨率、字体、字号、不透明度、描边、阴影、粗体、滚动通过时间、显示区域、轨道排满处理、重复合并、礼物/醒目留言过滤和屏蔽关键词。这组参数与播放页弹幕设置互不影响，改完重新导出即可。屏蔽关键词逐行填写，开启正则后按 Rust 正则编译，正则无效时导出明确失败。入场、社交和系统通知不写入字幕；过滤后无可显示弹幕时提示导出失败，不生成空字幕。

滚动容量由「显示区域」、字号和「滚动通过时间」共同决定。超出容量时按「轨道排满时」处理：默认「延迟」推后到最早空出的行，超过「最大延迟」（0–30 秒，默认 5 秒）才丢弃；「丢弃」直接舍弃；「重叠」保留全部但允许遮挡（2.4 及之前的行为）。刷屏房间建议同时调大显示区域、调小字号、缩短滚动通过时间并放宽重复合并，只改溢出策略无法增加容量。

## 4. 保存位置与目录结构

默认目录是当前应用数据目录下的 `recordings/`。在「设置 → 录制设置 → 保存位置」或录制库顶栏右侧的「保存位置」可查看当前目录、磁盘剩余空间、选择其他本地目录或「恢复默认」。切换时会把已有录制同步迁移到新目录；正在录制或收尾时需等待完成。开始录制要求能读取目标卷剩余空间并至少保留 512 MB。

媒体文件按「用户名_标题_开始时间」命名。每段录制是自包含目录，含 `metadata.json`、媒体文件和可选的 `danmaku.jsonl`，适合整体备份或复制。目录分两级：外层按「平台_房间号」聚合同一房间，内层按「主播名_开始时间」区分单次会话。

```
recordings/
└─ douyu_6979222/
   └─ 玩机器丶Machine_20260820-192158/
      ├─ 玩机器丶Machine_小众宝藏结晶直播间 6657_20260820-192158.flv
      ├─ danmaku.jsonl
      └─ metadata.json
```

同一房间多次录制并列在同一外层目录下，只有同秒开始的两次才追加序号。IPTV 没有房间号时使用来源中的频道标识。

> [!WARNING]
> 2.2 起改为上述两级结构。2.2 之前的单层目录（媒体直接放在「平台_房间号」下）不再被录制库识别，文件仍在磁盘上、不会被删除，需要时可手动播放或整理。

关闭应用窗口时若仍有录制进行，会提示任务数并询问是否退出：选「继续录制」保留窗口，选「结束录制并退出」才结束全部任务。正常退出会在 15 秒内等待媒体、弹幕轨和 metadata 收尾；未结束的任务保留已有内容，下次启动恢复为「已中断」。异常退出后下次启动同样会扫描并恢复可回放部分。

开始长时间录制前请检查目标磁盘空间，并只保存你拥有录制或回放权限的内容。

## 5. 相关设置

| 项 | 说明 |
|----|------|
| 本地录制 | 仅桌面端；后台录制并发路数可设（默认 4，范围 1–6），可配置本地保存目录、按时长自动分割、可选 `danmaku.jsonl` 弹幕轨，并可独立配置「导出 ASS 弹幕」；媒体、目录记录和弹幕均不进入 SQLite 或配置同步 |
| FFmpeg 录制 | 固定使用进程内 FFmpeg；可设置自动分割时长、读写超时（3–60 秒）、最大重连延迟（1–60 秒）和 HLS 分片重试次数（0–20），新任务开始时读取当前设置 |
| 默认弹幕轨 | 「设置 → 录制设置」调整新任务是否默认「包含弹幕」 |

FLV、HLS 和 MPEG-TS 统一通过进程内 FFmpeg 录制：只复制音视频包写入目标容器，不解码、不转码，也不需要外部 `ffmpeg` 可执行文件。FLV/MPEG-TS 保持原容器，HLS 写为单个 `.ts`，原生 MP4/WebM 原样保存。录制不会上传媒体。

## 6. 常见问题

**Q: 录制按钮为什么没有显示？**

A: 录制仅支持 Tauri 桌面端，Android、iOS、浏览器预览和未取得播放源的页面不显示入口。请确认已进入直播间或 `/iptv/play` 播放页，并在顶部标题栏右侧查找录制图标（直播间图标位于「定时关闭」旁）。

**Q: 离开直播间后录制会停止吗？**

A: 默认先询问，可选留在页面、继续录制并离开，或停止保存后离开；开始前开启「离开页面后继续录制」则直接后台继续。后台任务可在侧栏「录制」中停止并保存。应用进程被强制结束时，下次启动会标记为「已中断」并保留已写入内容。

**Q: 录制文件能直接复制吗？**

A: 可以。每段录制是自包含目录，媒体、metadata 和弹幕轨在一起。修改保存位置会把已有录制同步迁移到新目录，录制进行中或收尾时需等待完成。

**Q: 自动分割会影响原生 MP4/WebM 录制吗？**

A: 不会。自动分割只作用于 FLV、HLS 和 MPEG-TS 的 FFmpeg 录制。每个分段是独立录制目录，停止时用当前分段或首段卡片的停止入口即可结束整个任务。

**Q: 为什么某些加密 HLS 无法录制？**

A: HLS 清单、分片和标准 `AES-128` key 由 libavformat 读取，但录制不转码、不解 DRM。`SAMPLE-AES`、平台授权加密或无法写入 MPEG-TS 的编码会由 FFmpeg 报错；这不影响普通观看。

**Q: Twitch 录制在广告时段或录制一段时间后提前结束怎么办？**

A: Twitch 的 HLS 地址和 token 是短时有效的。录制任务会在 token 过期、广告临时清单、异常 `#EXT-X-ENDLIST` 或 `Commercial break in progress` 时重新申请同一清晰度并等待清单恢复。若仍显示「已中断」，请检查网络或应用代理能否持续访问 Twitch，并保留录制目录中的 `metadata.json` 和 `.ts` 文件以便诊断。参见[Twitch 平台 API 文档](Twitch平台API文档.md)。
