# IPTV 与投屏

本篇讲 IPTV 频道的浏览与播放，以及把直播投到局域网 DLNA 设备。
日常直播观看、弹幕和字幕见[用户指南](用户指南.md)。

## 1. IPTV 频道

左侧栏「IPTV」进入 `/iptv` 频道发现首页。发现页只展示来源、分类、搜索、可用状态和频道列表，**进入时不会挂载播放器或自动播放**；点击频道后才进入独立的沉浸式 `/iptv/play` 播放页。

### 选择频道源

- 内置：IPTV-org 官方日更的中文语言、中国大陆、东亚和综合公开频道分表。
- 自定义：在「设置 → 网络」保存你有权使用的 HTTP(S) M3U 地址，首页随后显示「自定义源」。该地址只保存在当前设备，不写入路由、历史或配置包。
- 直链播放：在同一分类下输入你有权使用的 HTTP(S) 媒体地址，直接进入播放器；应用按地址识别 HLS、FLV、MPEG-TS 或原生媒体。

两端顶栏都用页签切换来源（手机页签平分顶栏宽度）。手机为单列频道，搜索框与图标筛选按钮在列表上方；桌面为多列频道，搜索框与状态筛选在左侧栏顶部、分组导航之上。搜索支持多关键词按频道名/分组筛选，精确与前缀匹配优先展示，常用分组可一键选择，长列表按需展开。内置源不使用超过应用安全上限的全球总表。

### 更新与可用性检测

- 「更新源」按当前应用代理重新下载 M3U，成功后更新频道数与时间；触屏设备也可下拉更新。
- 「检测可用性」对当前搜索/分类结果按 URL 去重，最多检测前 120 个，逐批显示进度、响应耗时和失败原因，完成后可按「可用 / 不可用 / 未检测」筛选。检测不启动播放器，结果只属于当前页面会话，更新或切换来源后清除。
- 绿色「可用」只说明本次请求取得了媒体数据（HLS 另校验清单头），**不保证**后续分片、解码、地区授权或持续稳定。

### 关注与分组

关注或取消关注在播放页顶栏进行；浏览已关注频道用关注页的「IPTV 频道」页签，它汇总各来源的关注，频道源选择位于关注页左侧栏顶部（移动端在分组条上方）。桌面用左侧分组栏、移动端用横向分组条管理自定义分组，两端都可新建、重命名、删除分组，并从频道卡片调整归属；删除分组后频道进入「未分组」，M3U 自带分类仍作为元数据保留。

关注记录按来源和频道 URL 区分，保存名称、分组、台标、协议与必要请求头快照；源更新后暂时消失的已关注频道仍会显示，可用快照播放。内置公开源的关注与 IPTV 自定义分组包含在配置导入导出中；自定义源地址及其频道关注只留在当前设备。

### 播放页

`/iptv/play` 通过本机代理加载 HLS、MPEG-TS 或 FLV，以处理嵌套清单、分片和常见跨域限制。控制栏与直播间一致：重连、播放/暂停、静音/音量、仅播声音、画中画和全屏，播放时自动隐藏。全屏时左上角的「直播」徽标前出现返回箭头，点击退出全屏。焦点在画面时可用 `Space` / `K` 播放或暂停、`M` 静音、`F` 全屏。返回会回到保留来源、分类与搜索条件的频道列表。桌面端可在此页开始录制，见[录制与回放](录制与回放.md)。

节目内容与可用性由上游 M3U 来源决定，应用仅解析并播放配置的流地址。

## 2. DLNA 投屏

进入直播间后打开投屏菜单：桌面端在顶栏「定时关闭」旁的电视图标，移动端在右上角「更多房间操作」抽屉，全屏时在 HUD 的「更多房间操作」磁贴里。搜索同一局域网内的 DLNA 设备（智能电视、电视盒子等）并选择后，rLive 会在本机启动临时中继端口并把播放地址下发到设备。

直播流经本机中继转发，中继会注入上游要求的 UA/Referer 等请求头，因此电视无需直连源站；HLS 播放列表中的分片地址会自动改写为中继地址。

使用限制：

- 本机与电视必须接入同一局域网。
- 画面由电视端解码，能否播放取决于设备支持的协议与编码（FLV/HLS 兼容性因品牌而异）。
- 弹幕、清晰度切换等仅作用于本机播放器，不影响电视端。
- 断开投屏会向设备发送 Stop 并关闭本机中继；关闭对话框或离开房间不会中断已建立的投屏，需要显式断开。
