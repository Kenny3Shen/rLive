# 快手平台 API 文档

更新时间：2026-07-27。本页说明 rLive 对快手公开浏览和播放数据的接入范围。

## 能力总览

| 能力 | 状态 | rLive 行为 |
| --- | --- | --- |
| 推荐与分类 | 已支持 | 使用公开推荐和游戏分类数据；推荐页只展示可验证的首屏。 |
| 分区浏览与搜索 | 已支持（受限） | 搜索匹配游戏分区名称，再展示该分区直播间；不是主播/全文搜索。 |
| 房间详情与播放 | 已支持 | 从直播间初始状态解析主播、状态、清晰度和可用播放地址。 |
| 账号 | 未接入 | 当前不提供快手 Cookie 登录或账号操作。 |
| 实时弹幕接收 | 未支持 | 房间会明确显示不支持，不反复发起无效连接。 |
| 弹幕发送 | 未支持 | 不提供仅发送或网页报文复用功能。 |

## rLive 接入接口

适配器实现统一的分类、推荐、分区房间、搜索、详情、清晰度和播放 URL 接口。匿名首页不会稳定返回可复用的分页游标，因此第二页会明确返回空结果，而非用新首屏冒充下一页。游戏分区搜索同样只在找到匹配分区时展示对应房间，避免把分区搜索误写为主播搜索。

播放链路优先使用 H.264 可用地址，并附带网页所需的 Referer/User-Agent 给本机代理；实际清晰度和地址会随房间状态与上游策略变化。

## 当前边界

rLive 尚无快手实时弹幕接收，因此也不新增独立的发送功能。没有正常接收、身份状态、发送回包与真实回显的完整闭环时，单独逆向写入请求既不能形成可验证产品能力，也不应被视为官方 API。

如未来获得适用于桌面客户端的官方实时互动能力，应先实现接收、账号状态、错误处理、限频与回显，再评估用户主动发送。
