# 播放列表功能

## 概述

播放列表功能允许用户连续播放多个视频分集，支持正序/倒序播放、自动播放下一集等特性。参考了 [PiliPlus](https://github.com/bggRGjQaUbCoE/PiliPlus) 的实现。

## 功能特性

### 1. 播放列表管理

- **播放全部**：从第一集（或倒序时的最后一集）开始播放整个列表
- **加入列表**：从当前集开始设置播放列表
- **正序/倒序切换**：支持正序和倒序播放模式
- **播放进度显示**：显示当前播放位置（如 "3 / 12"）
- **列表连播**：从推荐、热门/分区、搜索、UP 主投稿或相关视频列表点开任意视频，该列表在点击时刻的快照即成为播放列表（后续加载更多不影响已建立的列表），从被点的视频开始连播
- **结构化列表优先**：多 P 稿件自动使用分 P 列表；没有多 P 但属于 UGC 合集（ugc_season）时使用合集列表，覆盖来源列表快照。侧栏的选集/合集页签可直接换集，PGC 分集不受影响

### 2. 自动播放下一集

- 普通详情模式下视频播放结束后，自动跳转到下一集（可在设置中关闭）；短视频模式不自动换片，而是循环当前视频
- 延迟 1 秒后开始播放，给用户反应时间

### 3. 跳转入口

- **播放下一个按钮**：控制条播放/暂停旁的「下一个」按钮（列表有后续项时出现）
- **键盘快捷键**：N 或 ] 播放下一集，P 或 [ 播放上一集
- **桌面滚轮**：画面内向下下一条、向上上一条，横屏项同样支持，沿队列顺序且不累积返回栈。连续惯性滚动只换一条；控件、菜单、详情滚动、横向滚动及缩放不会换片
- **竖屏短视频**：移动端识别到竖屏视频自动沉浸播放，有多项播放列表时上滑下一个、下滑上一个，切到横屏项仍保持竖屏沉浸和换片能力；跟手位移、快速甩动与回弹复用既有翻页算法。长按、横向起步、多指、取消与控件操作不切换；滑动不累积返回栈，列表边界提示后停留当前项。标题仅展示，评论入口或退出全屏按钮切到普通详情布局，再返回短视频时保留播放器、进度与暂停状态；详情滚动不换片
- **信息显隐**：短视频的进度条、控制栏常驻；隐藏按钮只切换头像、用户名、粉丝/视频数及视频标题的显示，评论入口和上下控制栏不受影响，同一按钮可恢复。头像跨两行，用户名位于右上，粉丝数与视频数位于右下；换片保持信息显隐状态
- **UP 投稿队列**：点头像打开既有投稿抽屉，选片后以已加载投稿替换来源队列并关闭抽屉。短视频只在 UP 投稿队列中显示 `x/y`，默认来源不显示；普通详情仍显示多项队列序号

### 4. 播放偏好

通过播放器控制栏的设置菜单可以配置（偏好持久化到 localStorage `video-playlist`）：

- 循环播放：开启/关闭。开启后播完当前视频从头重播，**优先于**自动播放下一集；单视频（无列表）同样可用
- 自动播放下一集：开启/关闭（仅列表多于一项时出现）
- 倒序播放：开启/关闭（对合集与列表连播同样生效）

普通详情模式播完后的动作由 `videoEndedAction(loopPlayback, autoPlayNext, hasNext)` 决定，优先级为循环 > 连播 > 停住；没有下一集时连播退化成停住。短视频模式临时以循环优先，不修改 `playlistStore` 的持久化偏好，也不因模式往返重建播放器。

## 技术实现

### 核心文件

1. **`src/features/video/playlistStore.ts`**
   - 播放列表状态管理（使用 Zustand）
   - 播放列表项数据结构
   - 播放顺序控制
   - 用户偏好持久化（localStorage）

2. **`src/features/video/VideoPlayerPage.tsx`**
   - 自动播放下一集逻辑
   - 键盘快捷键处理
   - 播放列表位置同步
   - 播放列表设置菜单
   - 来源队列优先；无有效来源时仅为多 P 直链建立选集队列，不因稿件带合集信息而替换来源

3. **`src-tauri/src/sites/bilibili/video.rs`**
   - `parse_archive` 解析 ugc_season，各分区分集展平为合集列表

4. **`src/features/video/VideoSidebar.tsx`**
   - 分集列表增强
   - 播放控制按钮（播放全部、加入列表、正序/倒序）
   - 播放列表项转换

### 数据模型

```typescript
type PlaylistItem = {
  id: string; // 唯一标识：`${bvid}_${cid}`
  bvid: string; // B 站视频 ID
  cid: number; // 分 P/分集 ID
  epId: string | null; // PGC 分集 ID（UGC 为 null）
  aid: string; // 稿件 av 号
  title: string; // 标题
  index: string; // 集号或分 P 序号
  duration: number; // 时长（秒）
  cover?: string; // 封面 URL
};
```

### 状态管理

播放列表状态通过 `usePlaylistStore` 管理：

- `items`：当前播放列表
- `currentId`：当前播放项 ID
- `reversed`：播放顺序（true = 倒序）
- `autoPlayNext`：是否自动播放下一集
- `loopPlayback`：是否循环播放当前视频（优先于 `autoPlayNext`）
- `uploader`：UP 投稿来源 `{ mid, name }`，普通来源与清空队列时为 `null`，不持久化

用户偏好（`reversed`、`autoPlayNext`、`loopPlayback`）持久化到 localStorage，播放列表状态在会话期间保持。

### 播放流程

1. 用户点击「播放全部」「加入列表」，从推荐/搜索/投稿等列表点开视频（已加载快照即列表），或主动点选分 P/合集分集
2. 分集/列表条目转换为 `PlaylistItem[]`
3. 设置播放列表到 store
4. 导航到目标视频播放页
5. 播放页同步当前播放项到 store；有效来源保持不变，无有效来源的多 P 直链才建立选集队列，其他直链清除残留队列
6. 视频结束时检查 `autoPlayNext` 和 `nextItem`
7. 自动跳转到下一集（如果有）

## 用户界面

### 合集页签（UGC）

稿件属于 UGC 合集时，右侧栏显示「合集」页签：合集标题 + 共 N 个 + 分集列表（序号/标题/时长，当前项高亮）。仅展示合集不改变来源队列；点具体分集才用合集替换队列并跳转。打开页签或连播换集时列表自动滚动到当前分集居中位置。

### 分集列表控制栏

在 PGC 分集列表顶部显示：

```
[播放全部] [加入列表]     [倒序/正序图标]
```

### 播放器控制栏

- 中间位置显示播放进度（如 "3 / 12"）
- 设置菜单中新增「播放列表设置」选项

## 限制与约束

1. **来源列表快照**：支持 UGC 列表、多 P、合集与 PGC 分集；无列表的直链不提供上下滑动切换，播放页不额外生成无限推荐流
2. **播放列表不持久化**：播放列表状态仅在会话期间保持，刷新页面后需要重新设置
3. **单一播放列表**：不支持多个播放列表或播放列表队列
