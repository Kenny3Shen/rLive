# 播放列表功能

## 概述

播放列表功能允许用户连续播放多个视频分集，支持自动切集、队列结束后自动连播相关视频等特性。参考了 [PiliPlus](https://github.com/bggRGjQaUbCoE/PiliPlus) 的实现。

## 功能特性

### 1. 播放列表管理

- **播放全部**：从第一集开始播放整个列表
- **加入列表**：从当前集开始设置播放列表
- **播放进度显示**：显示当前播放位置（如 "3 / 12"）
- **列表队列**：从推荐、热门/分区、搜索、UP 主投稿或相关视频列表点开任意视频时，点击时刻的列表快照成为播放队列（后续加载更多不影响已建立的队列）；键盘 `N` / `P` 与滑动切换沿队列进行，但推荐/热门/相关流的下一项不作为「自动切集」。
- **结构化列表优先**：多 P 稿件自动使用分 P 列表；没有多 P 但属于 UGC 合集（ugc_season）时使用合集列表，覆盖来源队列快照。侧栏的选集/合集页签可直接换集，PGC 分集不受影响

### 2. 播完后的连播

- **自动切集**（默认开启）：选集/合集、搜索和 UP 主投稿队列有下一项时，延迟 1 秒自动跳转下一项
- **自动连播**（默认开启）：队列没有下一项（含推荐/热门/相关流结束、最后一集播完）时，延迟 3 秒从当前视频的相关视频列表第一个接着播，本轮队列随之换成相关流；UGC 才会连播相关视频，PGC 剧集没有相关视频列表
- 两者都可关闭；都关闭时播完停在当前视频（进度仍记满，历史认定「已看完」）

### 3. 跳转入口

- **播放下一个按钮**：控制条播放/暂停旁的「下一个」按钮，只在该视频自身的选集还有下一集时出现，点击播放该集（不沿来源队列）
- **键盘快捷键**：N 或 ] 播放下一集，P 或 [ 播放上一集（沿当前队列）
- **UP 投稿队列**：在侧栏点 UP 主头像打开既有投稿抽屉，选片后以已加载投稿替换来源队列并关闭抽屉，时间轴旁显示多项队列序号

### 4. 播放偏好

通过播放器控制栏的设置菜单可以配置（偏好持久化到 localStorage `video-playlist`）：

- 循环播放：开启/关闭。开启后播完当前视频从头重播，**优先于**两种连播；单视频（无列表）同样可用
- 自动切集：开启/关闭（仅列表多于一项时出现）
- 自动连播：开启/关闭。开启后按上文延迟播放当前视频的相关视频；PGC 剧集不显示该项

- 播完后的动作由纯函数 `videoEndedAction(loopPlayback, autoPlayNext, hasNext, autoPlayRelated)` 决定，优先级为循环 > 连播下一集 > 连播相关视频 > 停住；推荐/热门/相关流的队列邻项不计入 `hasNext`，这类队列走完即落到相关视频；相关视频取不到（无 bvid 或列表为空）时停住。

## 技术实现

### 核心文件

1. **`src/features/video/playlistStore.ts`**
   - 播放列表状态管理（使用 Zustand）
   - 播放列表项数据结构（UGC 分 P / 合集分集 / PGC 分集各一个构造器）
   - `videoEndedAction` 决定播完后的动作，`nextSelectionItem` 取当前选集里的下一项
   - 用户偏好持久化（localStorage）

2. **`src/features/video/VideoPlayerPage.tsx`**
   - 播完后的连播逻辑（下一集 / 相关视频）
   - 键盘快捷键处理
   - 播放列表位置同步
   - 播放列表设置菜单
   - 来源队列优先；无有效来源时仅为多 P 直链建立选集队列，不因稿件带合集信息而替换来源

3. **`src-tauri/src/sites/bilibili/video.rs`**
   - `parse_archive` 解析 ugc_season，各分区分集展平为合集列表

4. **`src/features/video/VideoSidebar.tsx`**
   - 分集列表增强
   - 播放控制按钮（播放全部、加入列表）
   - 播放列表项转换（与播放页共用同一批构造器）

### 数据模型

```typescript
type PlaylistItem = {
  id: string; // 唯一标识：`${bvid}_${cid}`
  bvid: string; // B 站视频 ID
  cid: number; // 分 P/分集 ID
  epId: string | null; // PGC 分集 ID（UGC 为 null）
  aid: string; // 稿件 av 号
  title: string; // 标题
  index: string; // 集号或分 P 序号
  duration: number; // 时长（秒）
  cover?: string; // 封面 URL
};
```

### 状态管理

播放列表状态通过 `usePlaylistStore` 管理：

- `items`：当前播放列表
- `currentId`：当前播放项 ID
- `autoPlayNext`：是否自动切集
- `loopPlayback`：是否循环播放当前视频（优先于两种连播）
- `autoPlayRelated`：队列没有下一项时是否自动连播当前视频的相关视频
- `uploader`：UP 投稿来源 `{ mid, name }`，普通来源与清空队列时为 `null`，不持久化

用户偏好（`autoPlayNext`、`loopPlayback`、`autoPlayRelated`）持久化到 localStorage，播放列表状态在会话期间保持。

### 播放流程

1. 用户点击「播放全部」「加入列表」，从推荐/搜索/投稿等列表点开视频（已加载快照即列表），或主动点选分 P/合集分集
2. 分集/列表条目转换为 `PlaylistItem[]`
3. 设置播放列表到 store
4. 导航到目标视频播放页
5. 播放页同步当前播放项到 store；有效来源保持不变，无有效来源的多 P 直链才建立选集队列，其他直链清除残留队列
6. 视频结束时按 `videoEndedAction` 判定：循环重播、1 秒后跳下一集，或 3 秒后播相关视频第一个
7. 等待期间用户换片、暂停或关掉对应开关都会取消这次跳转

## 用户界面

### 合集页签（UGC）

稿件属于 UGC 合集时，右侧栏显示「合集」页签：合集标题 + 共 N 个 + 分集列表（序号/标题/时长，当前项高亮）。仅展示合集不改变来源队列；点具体分集才用合集替换队列并跳转。打开页签或连播换集时列表自动滚动到当前分集居中位置。

### 分集列表控制栏

在 PGC 分集列表顶部显示：

```
[播放全部] [加入列表]
```

### 播放器控制栏

- 中间位置显示播放进度（如 "3 / 12"）
- 设置菜单中新增「播放列表设置」选项

## 限制与约束

1. **来源列表快照**：支持 UGC 列表、多 P、合集与 PGC 分集；无列表的直链不提供前后切换，播放页不额外生成无限推荐流
2. **播放列表不持久化**：播放列表状态仅在会话期间保持，刷新页面后需要重新设置
3. **单一播放列表**：不支持多个播放列表或播放列表队列
